Configuration

Primary knobs live in shared/config.lua. Live dispatch values can also be tuned in MDT → Settings (admin).

Brand

Product chrome (MDT header, duty HUD tag, notification senders). Separate from RP agencies.

Config.Brand = {
    productName = 'On Duty Framework',
    hudTag = 'ON DUTY',
    mdtProduct = 'ON DUTY FRAMEWORK',
    mdtSubtitle = 'MOBILE DATA TERMINAL',
    signOnKicker = 'ON DUTY · SECURE SIGN-ON',
    notifySender = 'On Duty',
    notifyDispatch = 'On Duty Dispatch',
    notifyMedical = 'On Duty Medical',
}

Config.Admin = {

TableControls

Config.PursuitFlee chances, search mode, PIT/disable, call-in
Config.TrafficStopMark range, pull-over behavior
Config.VehiclesDepartment fleet models
Config.PoliceStationsStation locations / transport
Config.AgenciesRP agency labels (default BCSO)
Config.AudioServer-wide radio mute / priority tone
Config.KeybindsDefault key names for RegisterKeyMapping
Config.DebugForce pursuit, auto-duty, visualizers
