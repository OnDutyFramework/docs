Callouts

Built-in Lua callouts plus the in-game Callout Builder for custom JSON scenes.

Built-in (Lua)

Files under shared/callouts/ append to Config.Callouts. Edit weight, descriptions, scene models, and suspect states there.

  • suspicious_person
  • residential_burglar_alarm / commercial_burglar_alarm
  • medical_emergency
  • shots_fired

Callout Builder

MDT → Settings (admin unlock) → Callout Builder.

  • List / enable / weight / priority / category
  • Dispatch briefing (shown on accept + active call HUD)
  • Actors: suspect, victim, complainant, witness — models, counts, questions, states
  • Vehicles: parked, idling, wrecked, driven_by_actor (+ link actor role)
  • Test Spawn forces the callout near you
  • Saved to custom_callouts.json and hot-merged into the live pool
Shipped examples: traffic_complaint and minor_crash.

Custom schema (v1)

{
  "id": "traffic_complaint",
  "title": "Traffic Complaint",
  "description": "...",
  "dispatchBriefing": "Complainant on scene...",
  "category": "traffic",
  "priority": 2,
  "weight": 25,
  "enabled": true,
  "scene": {
    "type": "actors",
    "actors": [
      {
        "role": "complainant",
        "models": ["a_m_y_hipster_01"],
        "count": 1,
        "questions": [
          { "prompt": "What happened?", "response": "..." }
        ]
      },
      {
        "role": "suspect",
        "models": ["a_m_y_stwhi_01"],
        "states": [
          { "id": "cooperative", "label": "Cooperative", "weight": 3 }
        ],
        "questions": [
          { "prompt": "Do you know why I stopped you?", "response": "..." }
        ]
      }
    ],
    "vehicles": [
      {
        "role": "subject",
        "models": ["sultan"],
        "condition": "driven_by_actor",
        "linkActorRole": "suspect"
      }
    ]
  }
}

Waypoints

Tag saved locations to categories or specific callout IDs in the Waypoint Editor. Once any waypoint is tagged for a call, that call uses the dedicated pool instead of the shared one. Capture with Capture My Location or /fivemfr_coords.
