Features

What ships in On Duty Framework today (v0.29.0).

Duty

  • Unified F4 menu — go on/off duty with unique 3-digit callsigns
  • Duty ped swap or freemode with holster profiles
  • Unit specialty, display name, agency
  • Movable / scalable always-on duty HUD
  • Persistent shift stats and activity log

CAD / Dispatch

  • Server-authoritative weighted call generation with distance bias and location history
  • Alert banner, quick-accept, hide, multi-unit Join Call
  • En Route / On Scene, CAD notes, call outcomes
  • Mid-response stand-downs on selected callouts
  • Panic clears unassigned calls; pursuits can hold/clear the board the same way
  • Dispatch radio audio with per-player volume

Built-in callouts

Suspicious Person, Residential / Commercial Burglar Alarm, Medical Emergency, Shots Fired — plus custom JSON examples (Traffic Complaint, Minor Crash).

Traffic stops

  • Mark → emergency equipment → AI pull-over
  • Step-out, ID, reasons, passengers, search / tow
  • Flee and close-range reaction outcomes
  • Hold Left Shift to cancel a mark or fully conclude an active stop
  • Call in a fleeing vehicle as a CAD pursuit (hold X / F5)

Pursuits

  • Foot and vehicle pursuits; any unit can join
  • Aggressive flee AI, PIT, tackle, taser surrender, aim-to-order surrender
  • Search mode: last-known area on the map (no live pin); UTL timeout if not reacquired
  • On-screen pursuit action hints

Field interactions

  • ID, cuff/uncuff, frisk, escort, put in / take out of vehicle
  • Citations prepared in MDT, issued in the field
  • First aid / injured patients
  • Subject speech above the ped’s head
  • Role-scoped callout questions (suspect / victim / complainant / witness)

Fleet & radio

  • Department garage markers and trunk equipment (medic bag, etc.)
  • Handheld radio: backup, plate/person run, mechanic, clear scene, pursuits

Admin tools

  • Passcode-gated Settings panels
  • Live dispatch tuning
  • Waypoint Editor (capture, teleport, GPS, tag to callouts)
  • Callout Builder (author / test / save custom scenes)
