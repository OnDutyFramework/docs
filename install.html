Install

Drop the resource in, ensure it, set a passcode, go on duty.

Requirements

  • FiveM server (cerulean / Lua 5.4)
  • No ESX, QBCore, or database required for core duty/CAD
  • Folder name must match what you ensure (shipped as onduty)

Steps

  1. Place the onduty folder in your server resources directory.
  2. Add to server.cfg: 
    ensure onduty
  3. Set your admin passcode in shared/config.lua: 
    Config.Admin = {
    passcode = 'your-secure-passcode',
}
  4. Restart the resource or server.
  5. Press F4, enter a 3-digit callsign (100–999), go on duty.
Admin unlock: MDT → Settings → enter the passcode to unlock Waypoint Editor, Callout Builder, and server dispatch settings.
